# Code de conduite

Ce projet adopte le [Contributor Covenant v2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez respectueux, constructif et accueillant ; les comportements harcelants, discriminatoires ou
hostiles ne sont pas tolérés. Les manquements peuvent être signalés aux mainteneurs via les canaux privés de GitHub
(signalement d'un contenu ou message au propriétaire du dépôt). Les mainteneurs peuvent modérer, éditer ou supprimer
tout contenu ou contribution contraire à ce code.
