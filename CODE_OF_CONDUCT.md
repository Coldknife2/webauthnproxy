# Code of conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, constructive and welcoming; harassing, discriminatory or hostile behavior is not tolerated. Violations can be
reported to the maintainers through GitHub's private channels (reporting content or messaging the repository owner). Maintainers may
moderate, edit or remove any content or contribution that goes against this code.
