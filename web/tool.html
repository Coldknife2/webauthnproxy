Outil d'enrôlement de passkey

Cette page ne contacte aucun serveur. Elle crée une passkey dans votre navigateur et produit un fichier JSON (clé publique uniquement). La passkey ne donne aucun accès tant que ce fichier n'a pas été copié par un administrateur dans le dossier import/ du proxy.

Placez le fichier dans <DATA_DIR>/import/ (ex. cp remi.json data/import/). Le proxy l'importe en quelques secondes.
